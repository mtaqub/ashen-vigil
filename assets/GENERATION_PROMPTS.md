# Ashen Vigil visual generation prompts

All seven visual masters were generated with the built-in image-generation tool. These are the exact prompts used. Cropping, resizing, atlas splitting, transparency extraction, and PBR-map derivation were completed locally without changing the illustrated content.

Background-removal pass:

```text

Asset type: production Roblox game UI button-frame ornament prepared for background removal
Input image: Image 1 is the edit target.
Primary request: Change only the background and the empty interior of the button frame to one perfectly flat solid #00ff00 chroma-key color. Keep the complete button-frame artwork itself unchanged: preserve its exact geometry, proportions, cracked funeral-slate end caps, cinder-red ember notches, tarnished-gold rails, center diamonds, colors, textures, highlights, and placement.
Scene/backdrop: one uniform #00ff00 field extending behind, outside, and through the empty interior of the frame.

Invariant: edit only the background/empty interior; do not redesign, crop, move, scale, recolor, simplify, or distort the button frame.
```

The chroma background was removed locally with a soft matte, despill, and one-pixel edge contraction. The finished master was normalized to 1536×288, then downsampled to 1024×192 for Roblox upload.

## Audio generation

The WAV files were synthesized locally from deterministic oscillators, filtered noise, envelopes, delay taps, and crossfades. They did not use sampled or extracted commercial audio. The source generator is retained in the task workspace for reproducibility.
